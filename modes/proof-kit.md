# 模式：物证清单（proof-kit）

简历是「claims」，物证是「evidence」。本模式为你的目标职位建议 5 个可固定展示的物证，立刻建立可信度。

## 输入

- **简历**：`data/cv-base.json`
- **目标职位**（或通用方向）

## 输出：5 个物证建议

每个物证含四要素：
- **是什么**：具体形态（文档 / 截图 / 样本表 / 视频 / 工作场景照）
- **讲什么**：展示哪类能力
- **为什么有效**：招聘者为什么买账
- **你手里有什么 / 缺什么**：对照简历判断，缺的提示另行准备

## 对简历正文的影响

- 物证是**随附材料**，正文一般不动；
- 可在 summary / projects 加一句轻量钩子（如「可提供选品决策表样本」），但**不得夸大**；
- 物证应**呼应 `diagnose.md` 暴露的危险信号**——用证据填坑。

## 外贸 / 跨境 / AI 方向示例物证

1. **客户开发 SOP / 英文开发信模板库** → 证明成交靠方法论而非运气
2. **平台从 0-1 运营截图**（橱窗 / 数据 / 产品数）→ 平台运营硬证据
3. **AI 工作流产出样本**（选品决策表、含采购角色的客户清单，脱敏）→ 证明 AI 自动化真落地
4. **短视频 / 直播数据战绩后台图** → 增长能力直观证据
5. **海外驻外 / 跨文化沟通佐证**（工作场景、商务沟通样本）→ 最稀缺的差异化证据

## 复用

- 与 `diagnose.md` 联动：diagnose 找出的「缺证据」信号，由本模式给「补什么物证」；
- 物证不进 `cv-base.json` 正文，作为投递时的附件包。
