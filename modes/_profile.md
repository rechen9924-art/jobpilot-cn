## 你的薪资目标

**通用原则：**
- 用公开渠道查国内市场数据（BOSS 直聘、猎聘、看准网、职友集）；只读数，不读方向。
- **区分构成**：月薪 / 年薪、是否 13 薪、年终奖（几个月）、绩效、五险一金（公积金 5%–12%）、股票 / 期权。
- **试用期薪资**：法定下限通常为转正 80%，务必问清。
- 报价按岗位 title，不按技能；销售 / 商务看“底薪 + 提成”。
- 国企看职级工资表，外企看 global band，民企差异大。

## 你的地点政策（国内求职）

- **工作地**：以 `profile.yml → location.city` 为准；JD 工作地不在可接受范围 → 该维度降分，必要时标 `hard_stop`。
- **落户 / 居住证**：北上深等需落户城市，JD 写“可解决户口”为加分；不解决且你强依赖 → 记风险。
- **大小周 / 加班**：`culture_screen.require` 写明能否接受；JD 明确大小周而你不可接受 → Culture 维度压低。
- **出差**：明确可接受频率；JD 高频出差而你不可接受 → 记风险。
- **外企 / 出海岗**：涉及海外派驻或工作签证，确认由谁办理、周期。

## 国内求职补充提示

- **简历照片 / 年龄 / 籍贯 / 政治面貌**：部分国企、传统行业、职能岗习惯附照片；互联网 / 外企通常不需要。通过 `profile.yml` 的 `candidate.photo` 开启（默认关闭，ATS 更友好）。
- **招聘平台**：BOSS 直聘（直聊）、猎聘（中高端 / 社招）、智联 / 前程无忧（综合）、拉勾（互联网）、牛客（校招 / 技术）、脉脉（内推）。自动扫描见 `config/portals.yml`，注意合规与封号风险。
- **主动触达**：见 `modes/contacto-cn.md`（BOSS / 脉脉 / 猎聘 / 邮件 / 微信 / 海外话术）。
