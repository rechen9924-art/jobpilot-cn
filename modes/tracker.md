# 模式：投递追踪表查看（tracker）

读取并汇总 `data/applications.md` 的投递记录，给出管道概览与待跟进提醒。

> 本模式只读取、统计、提醒，不新增投递；新增记录应在 `contacto-cn.md`（第 5 步触达）里写入。

## 输入

- **数据源**：`data/applications.md`（由 `contacto-cn.md` 维护，列：公司 / 岗位 / 渠道 / JD链接 / 投递日 / 触达方式 / 匹配分 / 跟进记录 / 状态 / 备注）
- 该文件被 `.gitignore` 忽略，仅存于你本机，不会进入公开仓库

## 固定输出结构

1. **管道概览**：按「状态」分组计数（已投 / 已读未回 / 已聊 / 面试中 / offer / 拒 / 搁置），给出总数与分布
2. **高优跟进**：列出状态为「已读未回 / 已聊」且最近跟进日期较早的条目，提示按 `contacto-cn.md` 的跟进节奏（D1–2 / D3–5 / D7）推进
3. **风险预警**：标记「已投」超 7 天无进展、或「拒 / 搁置」条目，便于复盘
4. **匹配分分布**（如有）：按匹配分排序，标注明显偏低（如 < 3）的投递，提示是否值得继续跟

## 边界

- 若 `data/applications.md` 不存在或为空，明确告知用户「还没有投递记录，先用 `/jobpilot-cn contacto-cn` 生成话术并登记」，不编造数据
- 不读取、不渲染任何简历或 PII，只呈现用户已登记的投递表本身

## 触发示例

- “查看我的投递追踪表”
- “/jobpilot-cn tracker”
- “哪些投递该跟进了？”
